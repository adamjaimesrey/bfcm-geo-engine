# Product-category naming conventions (ecomusa.example native)

Governs Issue L. Two registers:
- **CANONICAL** — MUST be used in H1, H2/H3 headers, and table column/row headers.
- **ALLOWED IN BODY** — acceptable variations in body copy only.

The agent MUST flag LOUDLY any header/table term that is not the canonical form,
and any body term outside the allowed list. Never use off-vocabulary terms
(e.g. "traditional iron", "traditional steamer").

| Category | CANONICAL (headers + tables) | Allowed in body copy |
|----------|------------------------------|----------------------|
| Steam irons | Steam Iron / Steam Irons | steam iron(s) |
| Steam stations | Steam Station / Steam Stations | steam station(s) |
| Handheld steamers | Handheld Steamer / Handheld Steamers | handheld garment steamer(s); handheld steamer(s); garment steamer(s) |
| Handheld suction steamers (sub-category of Handheld Steamers; = AirLift Spin + Spin Deluxe) | AirLift Suction Steamer / AirLift Suction Steamers | must always contain "suction": airlift suction steamer(s); handheld suction steamer(s); vacuum suction steamer(s); suction steamer(s); suction handheld steamer(s) |
| Full size steamers | Full Size Steamer / Full Size Steamers | full size steamer(s) |
| Ironing boards | Ironing Board / Ironing Boards | ironing board(s) |
| Stick vacuums | Stick Vacuum / Stick Vacuums | stick vacuum(s) |
| Fans | Fan / Fans | fan(s) |

## Rules
- Headers + table headers: default to the CANONICAL column above, singular or plural as fits.
- "Handheld suction steamer" is a SUB-CATEGORY of Handheld Steamers; every reference to it (canonical or body) MUST include the word "suction".
- Body copy may use any listed allowed variant; anything not listed = flag.
- "traditional <category>" is never allowed — replace with the "steam"/native form.

## Context-specific variant: "Steam-Only Handheld Steamer"
- Use "Steam-Only Handheld Steamer" / "steam-only handheld steamer(s)" ONLY when a regular handheld steamer is
  compared side by side with an AirLift Suction Steamer (both are handheld, so plain "Handheld Steamer" is ambiguous there).
- In that context it is allowed in H1, H2/H3, meta and table headers as well as body copy.
- In any other context, do NOT use it; default to the canonical "Handheld Steamer(s)".
- Replaces the off-limits "traditional steamer" in suction-vs-handheld comparisons.
